---------------------------------------------------
HOW TO INSTALL FONTS & ASSETS
---------------------------------------------------

[Windows]
1. Extract this ZIP archive.
2. Double-click any TTF/OTF font files you downloaded.
3. Click "Install" at the top of the font preview window.

[macOS]
1. Double-click the ZIP archive to expand it.
2. Double-click the font file (TTF/OTF).
3. Click "Install Font" in Font Book.

[iPad / Procreate / Clip Studio]
1. Open Files app, extract the ZIP file.
2. Drag and drop font files into Procreate or Clip Studio Paint text engine.
